# 🏴‍☠️ Open Treasure Hunt

![Hacktoberfest 2026](https://img.shields.io/badge/Hacktoberfest-2026-blueviolet?style=for-the-badge)
![Status: Active](https://img.shields.io/badge/Status-Active-success?style=for-the-badge)

*A submission for the Hacktoberfest Open-Source AI Challenge Week 1: Touch Grass.*

**Open Treasure Hunt** is a real-world, proximity-based multiplayer game that transforms your local park or neighborhood into a live game board. 

Players are split into two teams: **Protectors** (hiding the treasure) and **Pirates** (hunting it down). Instead of staring at a map, your phone acts as a tactical walkie-talkie. A live AI Game Master tracks your physical GPS coordinates, analyzes your movement behavior, and sends contextual, geography-aware taunts and warnings based on your real-world surroundings.

* **[TabPFN](https://github.com/PriorLabs/TabPFN):** CPU-optimized tabular foundation model used to classify raw kinematic GPS data (speed, distance, direction) into tactical behaviors (e.g., "wandering" vs "tracking directly").
* **[Google Gemma 2 (2B)](https://huggingface.co/google/gemma-2-2b-it):** Open-weight LLM served via Hugging Face Inference SDK to act as the dynamic, real-time Game Master.
* **[Geopy](https://geopy.readthedocs.io/):** For calculating geodesic distances and reverse-geocoding physical terrain/street names to feed to the AI.
* **Flask & HTML5 Geolocation:** Web-first architecture requiring zero native app installations.

## How to Run the Game

To play the game, you run the server locally on your computer and connect to it using your mobile phones via VS Code Port Forwarding.

### 1. Prerequisites
* **Python 3.9+** installed on your machine.
* A free **Hugging Face Token** (Accept the Gemma 2 license on HF first).
* A free **TabPFN License Token** from [Prior Labs](https://platform.priorlabs.ai).
* **VS Code** (for easy port forwarding).

### 2. Installation
Clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/open-treasure-hunt.git
cd open-treasure-hunt

# Create and activate a virtual environment
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install required packages
pip install -r requirements.txt
```

### 3. Environment Setup
Create a `.env` file in the root directory and add your API keys:

```env
HF_TOKEN=hf_your_hugging_face_token_here
```
You can add tabpfn token or it will be generated by the code itself (automatically)!

### 4. Start the Server
Run the Flask application:

```bash
python app.py
```
The server will start at `http://127.0.0.1:5000`.

## How to Play

To get the game on your phones while outside, use VS Code's native port forwarding:

1. Open the project in **VS Code**.
2. Open the **Ports** panel at the bottom (`Ctrl + Shift + ~` or `View -> Terminal -> Ports`).
3. Click **Forward a Port** and enter `5000`.
4. Right-click the newly forwarded port, change **Port Visibility** to **Public**.
5. Copy the generated `https://...github.dev` address.
6. **Player 1 (Protector):** Open the link on your phone and select the Protector role.
7. **Player 2 (Pirate):** Open the link on your phone and select the Pirate role.
8. **Go outside!** As you move, your phones will stream GPS data back to your laptop, and the AI will update your dashboards with distance metrics and contextual taunts.
